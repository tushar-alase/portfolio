02DEVICE LIFECYCLE

FOTA & remote firmware maintenance

Remote firmware delivery over Wi-Fi and 4G, with a recovery path when an update cannot complete.

ESP32MSP430EC200U 4GHTTP / FTP
150 devices supported · 95% first-attempt success
Explore the engineering

The problem

Remote devices need to remain usable when a download is interrupted or a new firmware image fails checks.

My contribution

Designed update architecture for ESP32 and MSP430 systems. Implemented cellular FTP integration with ESP32 OTA APIs and rollback handling; developed a Python-to-device USB transfer for MSP430 testing before adapting the cellular workflow.

Technical approach

Stored and compared firmware versions in flash before downloading. ESP32 OTA used a partition scheme that retained the previous image while a new image was downloaded and checked, with boot selection and rollback handling. Wi-Fi used HTTP; EC200U cellular transfers used FTP. Interrupted or invalid downloads left the working firmware intact for a later retry.

Outcome & scope

The system supported 150 devices. First-attempt update success was 95%; rollback protected the remaining devices. Fault and recovery scenarios were exercised during development.

11EMBEDDED SECURITY

Pico 2 PIN-authentication lock

A keypad-and-LCD security lab implementing PIN verification, persistent credentials, and failed-attempt lockout.

Raspberry Pi Pico 2MicroPythonSHA-256I²C LCD
Implemented coursework / IoT & edge security
Explore the engineering

The problem

An embedded authentication system needs to verify a PIN without keeping the credential in plaintext.

My contribution

Implemented PIN setup and change flows, keypad scanning, masked display, salted hashing, persistent JSON storage, and failed-attempt lockout.

Technical approach

Used a PCF8574 I²C LCD and 4×4 keypad. Credential verification used a constant-time comparison routine; random salts accompanied stored SHA-256 hashes.

Outcome & scope

The lab explored credential handling and device-level authentication. A four-digit PIN still has a small search space, even when salted and hashed.
