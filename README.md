# Tushar Alase — Engineering Portfolio

Embedded firmware, industrial IoT, robotics, and edge computing.

GitHub Pages serves the main branch root. The live website uses index.html, favicon.svg, and Tushar_Alase_Resume.pdf. Fonts and styles are bundled in index.html for portable static deployment.

The original Astro project is included in Astro_Source.zip. Unzip it, run npm ci and npm run dev, and edit src/pages/index.astro and src/assets/styles/portfolio.css. Rebuild and publish static assets with the /portfolio/ base path. index.html can also be edited directly for simple text updates.

Adapted from Astrofolio by Vikas Kapadiya: https://github.com/vikas5914/Astrofolio. The upstream README states MIT licensing. Roboto fonts supplied through Fontsource use their upstream open font license.
